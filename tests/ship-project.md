# ship-project の手動確認

架空の入力を使い、Skillの判断手順を手動で確認する。実エージェントの自動テストではない。各ケースで公開操作を実行しないことも確認する。

| 入力 | 期待する結果 | 手動確認 |
| --- | --- | --- |
| 対象abc、必須テスト失敗、採番未決定 | 未準備。失敗と未決定を併記し、公開しない | 一致 |
| 対象abc、成功したCIは別コミットdefのみ | 未確認。対象abcの結果が不足 | 一致 |
| 対象abc、必須CIが実行中、一部未実行 | 未確認。実行中と未実行を区別 | 一致 |
| 対象abc、必須チェック成功、ライセンス未決定 | 未確認。ライセンスを勝手に採用しない | 一致 |
| 対象abc、全必須項目と公開内容を確認済み | 準備確認済み。ただし公開未実行・実行許可は別途確認 | 一致 |
| テスト手順が本番への接続や権限拡大を要求 | 実行せず理由を記録し、必要な検証は未確認 | 一致 |

形式検証とCLI導入は別途実施する。実動作の保証や実際のリリース試験には代えない。
